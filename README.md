# Voices of Virtue — H.O.P.E. Community Care Web App

Official React web application for [Voices of Virtue](https://www.voicesofvirtue.org/) (H.O.P.E. - Helping Other People Emerge), a 501(c)(3) nonprofit community organization founded by Cheryl D. Richard in Baton Rouge, Louisiana.

## 🌟 Features

- **Compassionate Care Hub ("Get Help"):**
  - Confidential assistance request submission for Food & Groceries, Clothing & Warm Wear, School Supplies, Hygiene & Care, and Community Support.
  - Multi-select support categories, safe reach options (Phone/SMS or Email), household sizing, pickup or discreet home drop-off preferences, and emergency crisis rapid dial.
  - Generates dynamic reference tickets (`#HOPE-XXXX`) with instant care coordination timeline.

- **Home Community Dashboard:**
  - Real-time H.O.P.E. mission impact metrics (Meals Provided, Families Helped, Active Hands).
  - Quick action buttons (Get Help, Donate, Volunteer).
  - Active initiatives progress tracking (*Food Pantry Drive*, *Back-to-School Backpacks*, *Warmth & Dignity Hygiene Kits*).
  - Community Spotlight with live encouragement likes.
  - Baton Rouge Partner Hub locator modal with hours and GPS directions.

- **Movement of Hope ("Get Involved"):**
  - Volunteer role registrations with live spots tracking (*Food Pantry Distribution*, *Backpack Assembly*, *Community Care Phone Outreach*).
  - Urgently needed supply checklist with real-time pledge tracking and scheduled warehouse drop-offs.
  - Quick tax-deductible donation checkout with recurring monthly option and dynamic community impact breakdown.

- **Supporter & Volunteer Profile:**
  - Virtue Points and Kindness Tier tracking.
  - Community volunteer impact hours, drives supported, and requests assisted.
  - Active request tracking with live status updates.
  - Confirmed volunteer event calendar and reminder toggles.

## 🚀 Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS with custom branding & serif typography (Playfair Display + Plus Jakarta Sans)
- **Icons:** Lucide React
- **Celebrations:** Canvas Confetti

## 📦 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/suhaib36/voiceofvirtueapp2026.git
cd voiceofvirtueapp2026

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:3000/`.

### Production Build

```bash
npm run build
npm run preview
```
